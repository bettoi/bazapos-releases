# BazaPOS for Windows

Download the newest installer from **[Releases](https://github.com/bettoi/bazapos-releases/releases/latest)** — the file named `BazaPOS-Setup-<version>.exe` — and run it.

A till that already has BazaPOS keeps itself up to date: new versions download in the background and install the next time BazaPOS is closed, or straight away from its settings (Ctrl+,).
